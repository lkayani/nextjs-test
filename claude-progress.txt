## API Endpoint Details

### /api/calculate
- Path: `/api/calculate`
- Method: POST
- Request Body: JSON object with `operation`, `a`, and `b` fields
- Operations: `add`, `subtract`, `multiply`, `divide`
- Response: JSON object with `success`, `result`, `operation`, and `operands` fields
- Example request:
  ```json
  {
    "operation": "add",
    "a": 5,
    "b": 3
  }
  ```
- Example success response:
  ```json
  {
    "success": true,
    "result": 8,
    "operation": "add",
    "operands": {
      "a": 5,
      "b": 3
    }
  }
  ```
- Example error response:
  ```json
  {
    "success": false,
    "error": "Cannot divide by zero"
  }
  ```

### /api/time
- Path: `/api/time`
- Method: GET
- Response: JSON object with multiple time representations
- Example response:
  ```json
  {
    "timestamp": "2026-01-09T17:04:00.000Z",
    "unix": 1767956640,
    "formatted": "Thursday, January 9, 2026 at 05:04:00 PM UTC",
    "timezone": "UTC"
  }
  ```

### /api/hello
- Path: `/api/hello`
- Method: GET
- Response: JSON object with `message` and `timestamp` fields
- Example response:
  ```json
  {
    "message": "Hello, Universe!",
    "timestamp": "2026-01-06T..."
  }
  ```
